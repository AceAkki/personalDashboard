# Personal Dashboard

A feature-rich personal dashboard built with **React**, powered by **Zustand** for state management and **React Router** for seamless navigation.

## 🚀 Features

- ✅ Task Manager
- 🌤️ Weather Updates
- 📰 News Feed
- ⏱️ Pomodoro Timer
- 📊 All-in-one organized dashboard

## 🛠️ Tech Stack

- React
- Zustand
- React Router
